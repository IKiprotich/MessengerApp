# 📱 Messenger App Clone

A fully functional clone of a messaging app built using **Swift**, **SwiftUI**, and **Firebase**. This project showcases real-time messaging, user authentication, and a sleek UI—all crafted with modern iOS development practices.

---

## 🚀 Features

- 🔐 User Authentication (Sign Up / Log In)
- 💬 Real-time Messaging
- 📱 Responsive UI with SwiftUI
- ☁️ Backend powered by Firebase (Auth, Firestore, and Storage)
- 📲 Seamless navigation with SwiftUI’s `NavigationStack`

---

## 🛠️ Technologies Used

- **Swift 5**
- **SwiftUI** for UI design and layout
- **Firebase Authentication**
- **Firebase Firestore** for real-time data

---

## 🧠 iOS Development Concepts Applied

This project demonstrates proficiency in several core iOS development concepts:

| Concept | Application in Project |
|--------|-------------------------|
|  **SwiftUI** | Declarative UI structure, ViewModifiers, NavigationStack, LazyStacks |
|  **MVVM Architecture** | Separation of UI and business logic using ViewModels |
|  **Firebase Integration** | Real-time database sync, Auth management, image uploads |
|  **Data Binding** | Two-way binding using `@State`, `@Binding`, and `@ObservedObject` |
|  **Asynchronous Programming** | Async data fetches using `async/await` |
|  **Form Handling** | Validations for login/signup forms |
|  **Custom Views & Components** | Reusable chat bubbles, input bars, buttons |
|  **Navigation & Routing** | Dynamic navigation with `NavigationLink` and conditional logic |
|  **User Defaults** | Local storage of session-related data (if implemented) |
|  **App Lifecycle Awareness** | Handling loading states and user sessions on app launch |
